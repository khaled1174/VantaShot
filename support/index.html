VantaShot Support

Email Khaledmk8718@gmail.com for help or privacy questions. For bug reports, use VantaShot support on GitHub. Include the app version/build, macOS version, and steps to reproduce the problem. Share captures or recordings only when you intend their contents to be public.

Screen capture or recording is blocked

Open VantaShot Settings → Permissions and About. Enable Screen Recording in macOS System Settings when requested. If macOS asks you to quit and reopen VantaShot, do so. Grant Microphone access only if you want to include microphone audio in a recording.

Choose a save folder

Use Settings → General → Choose Folder. The Mac App Store edition remembers the access grant for your chosen folder. If a folder or external drive is unavailable, choose another destination. Cancelling the folder picker leaves the capture available for a later Save.

Scrolling capture and keystrokes

In the Mac App Store edition, scroll the page yourself, then click Frame to add content and Finish to export the stitched capture. Automatic scrolling and the recording keystroke overlay are features of the direct-download edition. Registered global shortcuts remain available in both editions.

Projects, history and changing editions

Saved `.vantashot` projects can be opened through Finder or the editor. The Store edition uses its own sandbox storage. It does not import or delete the direct-download edition's capture history automatically. Keep the old history directory and exported files when changing editions. See the edition migration guidance below.

Desktop cover

If macOS does not allow VantaShot to read your wallpaper image, desktop icon hiding uses the dark or light cover selected in General settings. The editor lets you choose a background image when the desktop wallpaper cannot be loaded.

Keep existing projects and exported files when changing editions. The Store edition does not delete or automatically import the direct-download history folder.
